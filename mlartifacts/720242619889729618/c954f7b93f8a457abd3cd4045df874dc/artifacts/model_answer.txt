LoRA, which stands for Low-Rank Adaptation, is a strategy employed in machine learning to perform targeted fine-tuning of models. It involves updating only certain parameters or layers within an LMM (Large Multimodal Model) by introducing low-rank matrices that interact with the existing weights. This approach allows for modifying aspects specific to new tasks while retaining previously learned knowledge, effectively mitigating forgetting and facilitating better generalization across different domains without extensive retraining from scratch or overfitting on a single task stream. The LoRA method specifically targets this selective tuning by applying small updates that are computationally efficient yet sufficiently impactful for learning new skills with minimal performance loss in prior tasks (Sec. 5.1).
